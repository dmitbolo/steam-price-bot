# Steam Price Watcher Bot

Telegram-бот на Go для отслеживания скидок в Steam. Пользователь отправляет ссылку на игру и желаемую цену — бот сохраняет подписку в PostgreSQL и раз в сутки проверяет цены через конкурентный **Pipeline** на горутинах и каналах.

## Архитектура Pipeline

Проверка цен разделена на 4 независимых этапа, связанных каналами (`internal/pipeline`):

1. **Loader & Chunker:** Загружает активные подписки из БД, группирует их по `app_id` (без дублирования запросов для одной игры) и нарезает на батчи по **100 игр**.
2. **Steam Batch Fetcher:** С ограничением частоты (`time.Ticker`) запрашивает цены у Steam API пачками до 100 `appids` за один HTTP-запрос (`filters=price_overview`).
3. **Price Evaluator:** Сверяет текущую цену с порогом пользователя. Если цена упала ниже — обновляет `target_price` в БД на новый минимум (чтобы следующее уведомление пришло только при еще большем снижении цены).
4. **Telegram Notifier:** Отправляет уведомления пользователям в Telegram.

## Стек

* **Go 1.23+** (goroutines, channels, `context`, Graceful Shutdown)
* **PostgreSQL 16** (`jackc/pgx/v5`, `pgxpool`)
* **Telegram API:** `github.com/go-telegram/bot`
* **Инфраструктура и тесты:** Docker (Multi-stage build), Docker Compose, GitHub Actions CI, unit-тесты (`httptest`, `-race`)

## Быстрый старт

1. **Настройте окружение:** Создайте файл `.env` из шаблона и укажите в нем ваш `TELEGRAM_BOT_TOKEN`:
   ```bash
   cp .env.example .env
   ```

2. **Запустите проект:** Разверните всю инфраструктуру (базу данных, миграции и самого бота) в Docker одной командой:
   ```bash
   make docker-up
   ```

### Полезные команды (Makefile)

* **`make docker-logs`** — Просмотр логов контейнера бота.
* **`make docker-down`** — Полная остановка и удаление контейнеров.
* **`make db-up`** — Запуск только базы данных в Docker.
* **`make run`** — Локальный запуск бота (после поднятия БД через `db-up`).
* **`make test`** — Запуск тестов с включенным детектором гонок (`-race`).
* **`make cover`** — Генерация и просмотр отчета о покрытии кода тестами.
